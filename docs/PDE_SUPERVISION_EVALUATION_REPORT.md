## 一、 执行摘要与核心结论

针对“**当前使用 PDE 方程残差作为监督项是否有预测提升**”的问题，基于全量验证集（1110 个重叠时空滑窗）的严格物理评测与配对受控实验，给出客观结论：

1. **相对原始未微调模型（D0 基线）：没有提升，整体预测与物理指标均出现退化。**
   - 原始 D0 的标准 VRMSE 为 **0.258624**；引入 PDE 损失微调 50 步后（PDE-Step50）的标准 VRMSE 为 **0.264873**（**误差上升了 +2.42%**）。
   - 水平速度场 $u$ 的 RMSE 上升了 **+10.61%**，散度上升了 **+9.80%**，动量残差上升了 **+8.77%**。
   - **结论**：如果目标是拿出一个综合性能超越当前 D0 的新模型用于交付，**当前方案未能达成此目标，严禁将 PDE 候选模型替换 D0**。

2. **相对同等训练条件的继续微调对照组（P0 组）：表现出轻微且工况相关的物理正则化增益，但不足以抵消微调本身的退化。**
   - **点预测精度（VRMSE）**：PDE 组相对同预算 P0 仅微弱好转了 **-0.09%**（万分之九），在 $\mathrm{Sc}=0.1$（强扩散）下改善 -0.31%，而在 $\mathrm{Sc}=1.0$（强对流）下落后 P0 约 +0.039%，表现出工况依赖性。
   - **物理残差指标**：PDE 方程约束表现出明确的“正则化阻尼”作用，有效抑制了继续训练造成的物理流形漂移。相比 P0 组，示踪物输运残差下降 **2.18%**（$\mathrm{Sc}=0.1$ 下下降 **3.26%**），动量残差下降 **1.48%**，散度下降 **0.19%**。

3. **此前“提升 14%”的假象根因：局部窗口的采样选择偏差（Selection Bias）。**
   - 前期在 4 个样本、仅截取每条轨迹最前端 $t=0\dots 15$ 单一窗口（共 4 个早期窗口）上测得的 VRMSE 0.191669，完全是短程早期轨迹采样的局部偏差。
   - 一旦将评测尺度扩展到全验证集覆盖全部物理时间演化的 1110 个滑动窗口，均值立即回归到轻度退化区间。

## 二、 受控实验设计与评测基准

为彻底隔离实验变量，杜绝伪增益，本实验构建了严格的三方公平配对流水线：

```
                      ┌────────────────────────────────────────┐
                      │ 冻结基准模型 D0 (Step 0)               │
                      │ best_long_vrmse.pt (SHA: edddbe8a...)  │
                      └──────────────────┬─────────────────────┘
                                         │
             ┌───────────────────────────┴───────────────────────────┐
             ▼                                                       ▼
┌──────────────────────────────────────┐  ┌──────────────────────────────────────┐
│ P0 对照组 (原有损失微调)             │  │ PDE 实验组 (原有损失 + PDE 残差)     │
│ L_existing = L_MSE + 0.01*div + 0.05*vort│  │ L_PDE = L_existing + λ_mom*L_mom + λ_tr*L_tr│
│ λ_mom = 0, λ_tr = 0                  │  │ λ_mom = 2.5e-5, λ_tr = 4.0e-6        │
└──────────────────┬───────────────────┘  └──────────────────┬───────────────────┘
                   │                                         │
                   └─────────────────────┬───────────────────┘
                                         ▼
                      ┌────────────────────────────────────────┐
                      │ 全量验证集基准评测 (1110 个滑动窗口)   │
                      │ 6 条轨迹全覆盖, H=12, stride=1, FP32   │
                      └────────────────────────────────────────┘
```

### 1. 严格受控配置对齐
- **基础网络与初始权重**：两组完全从原始 D0 深度拷贝（Deepcopy），共享完全一致的参数起点。
- **训练数据流与优化器**：两组共享严格同一组预先采样的 400 个 Microbatches；优化器均为 AdamW（$\text{lr}=5\times 10^{-5}, \text{weight\_decay}=10^{-4}$，梯度裁剪模长 1.0）。
- **更新协议**：单卡 NVIDIA vGPU-32GB 上通过 `batch_size=2, grad_accum_steps=4` 严格等价实现有效批大小 $B_{\mathrm{eff}}=8$。
- **物理算子与尺度**：Navier–Stokes 动量残差与示踪物平流扩散残差采用 2/3 Orszag 谱截断去混叠；特征尺度归一化参数 $a_u=a_v=0.05, a_s=0.02$。

### 2. 全量验证评测协议
- **数据集**：`grouped_split.json` 规定的完整 `valid` 分区（4 条 $\mathrm{Sc}=0.1$ 轨迹，2 条 $\mathrm{Sc}=1.0$ 轨迹）。
- **时间窗口**：时序跨度 $L=4$（历史帧）+ $H=12$（预测视界）= 16 帧。滑动步长 $\text{stride}=1$，遍历全部 1110 个可用滑窗。
- **物理量度规范**：在物理空间施加零均值压力规范（Zero-mean gauge），调用权威 `compute_vrmse()` 评估 The Well 基准标准指标。

## 五、 物理机理与实验发现总结

### 1. 为什么“微调本身导致退化”？
- 原模型 D0 是在大规模多步 Rollout 和预定学习率调度（Scheduler）下收敛出的精细平衡态。
- 在当前受控实验中，使用固定学习率 $\text{lr}=5\times 10^{-5}$ 在 $H=12$ 上强行继续微调，破坏了原网络在隐空间已形成的稳定动力学吸引子，导致误差累积反弹（过拟合到微调 batch 流，全局 VRMSE 退化 2.4%~2.5%）。

### 2. PDE 监督项的本质角色：物理正则化锚点，而非提分外挂
- 实验数据显示：在微调造成模型整体向高误差区域漂移的过程中，**加入控制方程残差（Navier–Stokes 与示踪物平流扩散）能够形成物理反作用力**。
- 它迫使解码后的物理场更贴合控制方程，因而抑制了散度与动量/示踪物残差的恶化幅度（残差全面低于 P0 组 1%~3%）。
- 但由于点预测误差的主要驱动源在于继续微调本身引入的参数扰动，PDE 项作为附加损失，其梯度量级不足以单独扭转微调导致的退化。

### 3. 统计边界澄清
- 本评测包含 1110 个滑动窗口，但来自 6 条固定轨迹且步长为 1，窗口之间存在高度的时间相关性。
- **1110 个时空窗口不能视为 1110 个独立重复样本**。当前数据能够确认“宏观趋势上 PDE 仅有极微弱收益”，若要确认万分之九的统计显著性，必须依赖多 Seed 或跨轨迹的更高层独立统计。

## 七、 最终工程决议与建议

| 决策项 | 执行决议 | 依据与理由 |
|---|---|---|
| **生产模型基准** | **继续保留原始未微调的冻结 D0 模型** | 全体验证集上 D0 VRMSE (0.2586) 仍为全局最低，所有更新模型均未击败 D0。 |
| **`pde_step_50.pt` 晋升** | **坚决否决晋升** | 全量评测下相对 D0 退化 +2.42%，此前 14% 提升已被证实为局部滑窗偏差。 |
| **超参数网格调优** | **立即停止在当前微调模式下的调参** | 恒定学习率微调无法拉回继续训练造成的点精度损失，单 Seed 调参边际收益极低。 |
| **测试集（Test Split）保护** | **继续保持绝对物理隔离** | 测试集未参与本轮探查、微调及候选筛选全流程，保证后续最终评估的严密性。 |

### 下一步技术路线建议
1. **成果封存**：将当前开发完成的物理去混叠算子、受控配对训练流水线和全量时空评测工具作为基建资产归档至代码库。
2. **转向更高收益的技术路径**：如果未来仍需引入 PDE 约束，应将其置于**基础预训练阶段（联合从头训练）**或采用**极小学习率余弦退火策略**，避免后期粗暴微调对隐空间流形的破坏；当前研发精力应转回概率扩散、网络容量扩展等收益更显著的方向。
